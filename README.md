# Kahoot Node.js Automation Tool

A foundational script that uses `kahoot.js-updated` to connect automated testing clients to live Kahoot games.

## Setup Instructions
1. Download the repository source files.
2. Open your terminal in the project directory and run:
   ```bash
   npm install
   ```

## How to Run
1. Open `index.js` and change the `GAME_PIN` to your active test game pin.
2. Start the script:
   ```bash
   node index.js
   ```
